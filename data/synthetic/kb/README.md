# Sample knowledge base (synthetic)

`gct_kb.jsonl` is the retrieval knowledge base of the fictional sample tenant, GulfConnect Telecom: tariffs, plans,
policies and operating procedures. Every document, identifier and figure is generated; none comes from a real
company or person. The scenario tests (`gateway/tests/scenarios/`) and the gateway image load it.

Replace it with your own approved documents through `aiva-admin kb-ingest`.
